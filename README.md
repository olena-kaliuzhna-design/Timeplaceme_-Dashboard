# TIMEPLACEME: прототипи дашбордів

Два дашборди на одній дизайн-системі:

| Сторінка | Для кого | Файл |
|---|---|---|
| **Admin overview** | Команда TIMEPLACEME | `admin/index.html` |
| **Partner dashboard** | Бізнеси-партнери (два стани: новий і активний партнер) | `partner/index.html` |

Обидва працюють у світлій і темній темі. Тема береться з налаштувань ОС, а перемикач запам'ятовує вибір. Верстка адаптивна, і жодних залежностей чи збірки немає.

## Як запустити

```bash
# будь-який статичний сервер, або просто відкрийте index.html у браузері
npx serve .
```

**GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root. Головна сторінка, `index.html`, веде на обидва дашборди.

## Структура

```
index.html               — вибір дашборда
admin/index.html         — внутрішній огляд
partner/index.html       — кабінет партнера
assets/css/app.css       — дизайн-токени (light/dark) і компоненти
assets/js/ui.js          — іконки, тема, SVG-графіки з тултіпами, воронка
assets/js/admin.js       — рендер адмінки
assets/js/partner.js     — рендер кабінету партнера
data/admin-data.js       — дані адмінки (з продакшн-скрінів 14.11.2026)
data/partner-data.js     — демо-дані партнера
docs/AUDIT.md            — аудит поточної адмінки та кабінету
docs/METRICS.md          — визначення метрик і контракт даних для бекенду
```

## Інтеграція в продукт (Rails `/backend`, `/customers`)

1. Розмітку з `admin/index.html` перенести в layout і view `backend/dashboard`, а `partner/index.html` — у `customers/dashboard`.
2. `app.css` підключити як окремий стилшит або перенести токени (`--brand`, `--surface`…) у вашу тему.
3. Замінити `window.ADMIN_DATA` / `window.PARTNER_DATA` на JSON з ендпоінтів, наприклад `GET /backend/dashboard.json`. Форма об'єкта описана в `docs/METRICS.md`.
4. Перемикач «Demo state» у кабінеті партнера потрібен тільки для прототипу. У продукті стан визначається тим, чи є в партнера хоча б одна опублікована подія.

## Що в даних справжнє

- **Адмінка:** усі лічильники, списки, партнери й події взяті зі скрінів продакшну за 14 листопада 2026. Денні графіки приблизно зчитані з наявних чартів.
- **Партнер:** «Casa do Fado (sample)» — вигаданий партнер для демонстрації дизайну з наповненням. У реального демо-акаунта поки нулі.
